Installation

Requirements

Warcraft III: The Frozen Throne (v1.26a) Warcraft III Loader Configured BNET Gateway

If you don't have Warcraft III installed

Download the pre-packaged client below, which includes Warcraft III Loader and AHT Hotkeys.

Download client

If you already have Warcraft III installed

1. Install Warcraft III Loader.

2. Configure your BNET Gateway to point to the Binig.NET server address.

3. Launch Warcraft III through WC3Loader and log in to play.
