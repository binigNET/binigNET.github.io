Bot Commands

Type in lobby or game chat, prefixed with !, e.g. !ready. Click a command to copy it. Commands marked Verified need a verified account: whisper sc to the bot on Battle.net.

Info

Bot + server info

  • !version Anywhere

    Bot version

  • Anywhere

    Discord invite link

  • !reconnect Anywhere

    GProxy download link, auto-reconnect on disconnect

  • !git Anywhere

    Bot source repo link

  • Anywhere

    Bot connection status, lobby listed or not

  • Anywhere

    How to verify account

    Whisper "sc" to bot on Battle.net to verify

  • !listgames !getgames Verified Anywhere

    List open lobbies + running games

  • !statsdota Verified Anywhere

    Player stats. statsdota = DotA stats

    !stats [NAME@REALM]

    No name = yourself

Lobby

Before the game starts

  • !r Lobby

    Mark yourself ready

  • !afk Lobby

    Mark yourself not ready

  • !comprace Lobby

    Set your race

    !race <human|orc|undead|elf|random|roll>
  • Lobby

    Pin msg shown to everyone who joins

    !pin <MESSAGE>

    Max 140 chars

  • Lobby

    Remove your pinned msg

  • !checkready !askready Lobby

    List who isn't ready

  • Lobby

    Whisper game invite to a friend

    !invite <NAME@REALM>
  • Lobby

    Claim lobby ownership

    Only if lobby has no owner

  • !s !go !g !vs Lobby

    Start game countdown

    Only if owner enabled freestart or lobby has no owner

Players & status

Check players, pings, map

  • !checkme Lobby + game

    Slot, ping, realm, verified, owner info

    !check [PLAYER]

    No name = yourself

  • !game !races Lobby + game

    Map info + everyone's race

  • !getobservers Lobby + game

    List players + observers

  • !p !pingall Lobby + game

    Everyone's ping

  • Lobby + game

    Game latency + sync tolerance

  • !url Lobby + game

    Map download URL

  • !dc !disconnect Lobby + game

    Disconnect yourself

In game

While playing

  • In game

    Your current + max APM

  • In game

    Drop lagging players

    Anyone if owner gone/lagging, else owner only

  • Lobby + game

Random & fun

  • !coin !coinflip Anywhere

    !flip [CHANCE%]

    Random pick from options

    !pick <A>, <B>, ...
  • Anywhere

    Random player

  • !pickobserver Lobby + game

▶ Lobby owner (16)

Owner = whoever hosted. No owner? Any player can claim with !owner. Admins can use these too.
  • !s !go !g !vs Lobby

    Start countdown. force = skip ready checks

    !start [force]
  • !a Lobby

    Stop countdown + autostart

  • !as Lobby

    Auto start at N ready or after M min

    !autostart <SLOTS>, <MINUTES>
  • !sw Lobby

    Swap two slots

    !swap <P1>, <P2>
  • !o Lobby

    Open slot. open kicks occupant, o does not

    !open <SLOT>
  • !c Lobby

    Close slot. close kicks occupant, c does not

    !close <SLOT>
  • !k !ckick !closekick Lobby + game

    Kick player. ckick also closes slot

    !kick <PLAYER>

    In game: laggers only

  • !bot Lobby

    Add computer. Default insane

    !comp [SLOT], [easy|normal|insane]
  • !compall Lobby

    Fill open slots with computers

    !fill [easy|normal|insane]
  • !reserve Lobby

    Reserve slots for names

    !hold <P1>, <P2>, ...
  • !sp Lobby

    Shuffle players

  • Lobby

    Give ownership to someone

    !owner <NAME>
  • Lobby + game

    Only owner can use cmds. With name: lock one player

    !lock [PLAYER]
  • !uh Lobby

    Close lobby

  • In game

    End game

  • !rmk In game

    End game, rehost as new lobby
